# SQL Data Analysis Project

## Project Overview
This project performs data analysis using SQL on 
real-world datasets including retail and mobile 
manufacturing data.

## Tools Used
- MySQL - Database creation and querying
- SQL - Data analysis and reporting

## Project Structure
### 1. Mobile Manufacture Data Analysis
- Analysis of mobile manufacturing data
- Database creation and table design
- SQL queries for insights

### 2. Retail Data Analysis
- Customer data analysis
- Product category analysis
- Transaction data analysis

## Skills Demonstrated
- Database Creation
- Data Querying
- Joins and Aggregations
- Data Filtering
- Report Generation
